# SafeKeyPass

**Claim:** `implements RAE 1.0.4 L1, enforcement tier`

SafeKeyPass is the enterprise distribution of the local-first authentication
broker for AI agents. It implements RAE at L1 (registered): organization-verified
identity, a signing credential bound to authorization records, pre-attribution
records with declared scope, no-RAE handling in the enforcement tier, and a
published conformance statement.

- **Repository:** `o3willard-AI/safekeypass` (private)
- **Conformance statement:** `RAE-CONFORMANCE.md` at the repository root
- **Date:** 2026-11-21
